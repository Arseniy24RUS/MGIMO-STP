Favicon-наборы

Иконки сделаны путём ресайза и центровки официальных логотипов/знаков из релизного логопакета. AI-генерация не использовалась.

Доступные наборы:
- mgimo: МГИМО. Основа: официальный знак здания МГИМО из логопакета.
- priority-2030: Приоритет 2030. Основа: официальный сокращённый знак Приоритета 2030.
- minobrnauki: Минобрнауки России. Основа: официальный гербовый знак Минобрнауки из логопакета.
Варианты фона внутри каждого набора:
- transparent — цветной официальный знак на прозрачном фоне.
- light — цветной официальный знак на белом фоне #FFFFFF.
- dark — белая официальная версия знака на тёмном фоне #0A132D.

Файлы:
- favicon.ico — multi-size ICO.
- favicon-16x16.png, favicon-32x32.png, favicon-48x48.png, favicon-64x64.png.
- apple-touch-icon-180x180.png.
- android-chrome-192x192.png, android-chrome-512x512.png.
- site.webmanifest.

Пример подключения:
<link rel="icon" href="/favicons/mgimo/transparent/favicon.ico" sizes="any">
<link rel="icon" type="image/png" sizes="32x32" href="/favicons/mgimo/transparent/favicon-32x32.png">
<link rel="apple-touch-icon" href="/favicons/mgimo/transparent/apple-touch-icon-180x180.png">
<link rel="manifest" href="/favicons/mgimo/transparent/site.webmanifest">

Для основных страниц СТП рекомендуется набор mgimo/transparent или mgimo/dark в зависимости от технической реализации сайта. Наборы priority-2030 и minobrnauki предназначены для специальных партнёрских/служебных поверхностей, где favicon должен отражать программный или ведомственный контекст.
