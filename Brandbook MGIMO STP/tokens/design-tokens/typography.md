# Typography

Primary family: Onest.

- Headings and emphasis: Onest Medium.
- Body text: Onest Regular.
- Fallback if Onest is unavailable: Arial Bold / Arial Regular.
- Letter spacing: 0 for landing text.

## English logo lockups

- Generated MGIMO English lockups use editable SVG text with Arial/Onest fallbacks.
- Generated Minobrnauki English lockups use Arial/Onest fallback text and are labeled generated, not official.
- Official Priority 2030 Latin logos keep their original typography from the supplied brandbook files and must not be retyped or recolored.

These notes mirror the Figma token frame for the STP MGIMO landing concepts and document the generated English logo assets in this kit.
