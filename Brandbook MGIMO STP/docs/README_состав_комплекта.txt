Комплект подготовлен как релизный пакет для заказчика.

В КОРНЕ АРХИВА
- MGIMO_STP_brandbook.pdf
- MGIMO_STP_brandbook.pptx

Эти два файла являются брендбуком и не изменялись при обновлении архива.

СТРУКТУРА ПАПОК
logos
  Полный логопакет MGIMO, Приоритет 2030 и Минобрнауки. Сохранены рабочие форматы PNG, SVG, AI и превью-листы.

figma
  Актуальная локальная Figma-копия digital-шаблона MGIMO STP. Файл находится в figma/source/MGIMO_STP_landing_page_concepts.fig.

visuals
  Фото-иллюстрации и прикладные визуалы, используемые в брендбуке. Новые проектные hero-иллюстрации лежат в visuals/project-covers.

graphics
  Кубический модуль и орнаментальные элементы в PNG и SVG.

tokens
  Цветовые и типографические токены для digital-работы.

favicons
  Favicon-наборы для MGIMO, Приоритет 2030 и Минобрнауки: transparent, light и dark. Иконки сделаны на основе официальных логотипов/знаков, без AI-генерации.

previews
  Быстрые превью брендбука, визуалов, проектных обложек и favicon-наборов.

ВАЖНО
- В релизный пакет не включены логи, промпты, build-скрипты и служебные рендеры.
- Шрифтовые файлы не включены. Рабочая пара: Onest Medium / Onest Regular. Системный fallback: Arial Bold / Arial Regular.
- Для тёмных поверхностей используйте только белую версию логотипа Минобрнауки.
- Для русскоязычных материалов используйте русскоязычный логотип Приоритета 2030.
- Не растягивайте логотипы и не изменяйте их пропорции при подготовке web и PDF-материалов.
