КРАТКАЯ ПАМЯТКА ПО ЛОГОТИПАМ

1. MGIMO в институциональной строке всегда стоит первым.
2. Для русскоязычных поверхностей используйте русскоязычные версии логотипов.
3. Для англоязычных поверхностей используйте только англоязычные версии в пределах одной строки.
4. Цветная версия Минобрнауки допустима только на светлом фоне.
5. На тёмном фоне используйте только белую версию Минобрнауки.
6. Не деформируйте логотипы по ширине и высоте.
