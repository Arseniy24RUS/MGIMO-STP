# MGIMO Strategic Technological Projects

Release version of the bilingual MGIMO Strategic Technological Projects landing page.

## Live site

https://arseniy24rus.github.io/MGIMO-STP/

The site is published with GitHub Pages from the root of the `main` branch. It is a static HTML/CSS/JavaScript project and requires no build step.

## Structure

- `index.html` - landing page
- `project-*.html` - project pages
- `personal-data-consent.html` - personal data consent notice
- `assets/` - release images, logos, fonts, icons, map libraries and project media
- `Brandbook MGIMO STP/` - complete MGIMO STP brandbook source package

## Cooperation form

The form submits through FormSubmit to `project_office@inno.mgimo.ru`. FormSubmit requires a one-time mailbox confirmation before real requests are delivered. Until an authorized MGIMO employee confirms the activation email, delivery must be treated as pending.

The personal data notice must receive final legal approval from MGIMO before public promotion of the form.

## Deployment

GitHub Pages source: `main` branch, `/ (root)` directory. The `.nojekyll` file keeps all release assets available without Jekyll processing.
